Your Claude System

A private, self-maintaining assistant built on Claude. Your notes and decisions live in a private repository that only you and Claude can read, and routines keep it current every night.

What you get

  • Guard hooks. Claude is blocked from reading your credentials, cannot run destructive commands, and every action is logged with secrets masked.
  • Credentials stay out of chat. Keys are loaded by scripts; they never appear in a conversation.
  • Current facts and history, kept apart. Every client page has one place for what is true now and one for what happened.
  • Nightly self-healing. Duplicates, contradictions, and stale facts are found and flagged. Duplicate detection runs in-process, so your notes are never sent to a third-party embedding service; routines run in Claude's cloud on your private repository.
  • A knowledge graph rebuilt from your notes, so context is easy to find.
  • The System Journal. Every session leaves a small evidence record, and the telemetry report shows where the system wastes effort, so improvements are evidence-based.
  • Session telemetry. It shows where the system wastes effort, and /opportunity-scan works on any session.
  • The same hooks everywhere, in the cloud and on your computer.
  • Recall with a trust order. When it looks something up, it knows which sources to believe first.
  • An end-of-day routine that closes what it can prove and reaches you when something needs you.
  • Nothing to provision. No servers to set up and no terminal to learn.

What you need

  • A GitHub account.
  • A Claude Max plan. Routines and cloud sessions need it.

Later, to add your own computer: Claude Desktop, GitHub Desktop, and Git (on Windows, also Python 3). On a Mac, give Claude Desktop the Accessibility and Screen Recording permissions.

What happens next

  1. Your private repository appears under your GitHub account.
  2. Open it in Claude, choose brain, and the setup starts by itself.
  3. It asks for your discovery interview transcript, or five short questions if you do not have one.
  4. It builds your vault and schedules the routines.
  5. Then it walks you through putting it on your computer.
