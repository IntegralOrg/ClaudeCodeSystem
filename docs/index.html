Your Claude System

A private, self-maintaining assistant built on Claude. Your notes and decisions live in a private repository that only you and Claude can read, and routines keep it current every night.

Start in Claude Get Claude Desktop

What you get

  • Guard hooks. Claude is blocked from reading your credentials, cannot run destructive commands, and every action is logged with secrets masked.
  • Credentials stay out of chat. Keys are loaded by scripts; they never appear in a conversation.
  • Current facts and history, kept apart. Every client page has one place for what is true now and one for what happened.
  • Nightly self-healing. Duplicates, contradictions, and stale facts are found and flagged. Duplicate detection runs in-process, so your notes are never sent to a third-party embedding service; routines run in Claude's cloud on your private repository.
  • A knowledge graph rebuilt from your notes, so context is easy to find.
  • The System Journal. Sessions leave a small evidence record as they end, and the telemetry report shows where the system wastes effort, so you can see what to change.
  • Session telemetry. It shows where the system wastes effort, and /opportunity-scan works on any session.
  • The same hooks everywhere, in the cloud and on your computer.
  • Recall with a trust order. When it looks something up, it knows which sources to believe first.
  • An end-of-day routine that closes what it can prove and reaches you when something needs you.
  • Nothing to provision. No servers to set up and no terminal to learn.

What you need

  • A Claude Pro or Max plan. Routines and cloud sessions need it.
  • A Mac or a Windows PC. A free GitHub account helps; setup walks you through making one.

Three steps

  1. Install Claude Desktop and sign in.
  2. Press Start in Claude. Your browser asks once, "Open Claude?": say yes. Claude opens with the first message already written.
  3. Click Trust, then press Enter. Setup does the rest and tells you the one thing to click each time it needs you.

Setup downloads your system into a folder called Brain, installs what it needs, asks a few quick questions, and connects it to GitHub. You click two permission switches for Claude Code on a Mac, an installer, and one approval on GitHub.

If the button does nothing, copy the line below, open Code in Claude Desktop, choose your home folder, paste it as the first message, click Trust, and press Enter.

For whoever introduces it

Your Claude system now keeps itself honest: it blocks credential leaks, it notices when its own notes contradict each other, and it records its sessions so there is evidence to work from, not memory.

  • Safety. Guard hooks block reading credentials and destructive commands, and every action is logged with secrets masked. Your repository is private.
  • Accuracy. Each fact has one current home and one history. A nightly pass finds duplicates, contradictions, and stale facts, same-subject merges wait for your decision, and removals are staged, never deleted.
  • Improvement. Sessions are recorded as they end, and /opportunity-scan answers what change would have prevented a bad session. Automatic self-tuning from repeated friction is planned as a step in the nightly Vault Hygiene run.
